# AGENTS.md - Family Hub

## Purpose

Family Hub is a private, single-household Node.js PWA for calendars, tasks, and
paired wall displays.

## Working rules

- Read and follow `INSTRUCTIONS.md` and `CONTRIBUTING.md`.
- Ask before dependency, public-interface, major-design, schema, migration, or
  deployment changes.
- Ask before branch, commit, push, pull-request, or remote issue actions.
- Do not access or expose secrets, private household data, live databases, or
  backups without explicit approval.
- Preserve household isolation, authentication checks, and wall-display
  permission boundaries.
- Run `npm run check` and `npm test` for code changes.
- Report changed files, checks, risks, assumptions, and deferred work.
