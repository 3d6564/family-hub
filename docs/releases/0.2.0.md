## Changes

- Use `SITE_URL` for the browser address. The older `APP_ORIGIN` and `ALLOWED_ORIGINS` names still work.
- Keep the wall display on the same address as `SITE_URL` after HTTPS is enabled.
- Add an optional update notice. It is off by default and does not install updates.
- Deploy only from the published image.

## Setup changes

Set `SITE_URL` to the address you type in the browser, such as `https://hub.home.example`. The image published as `0.1.0` does not read `SITE_URL`. This image does.

No Raspberry Pi is changed by publishing this image. Deploy it separately when you want that host to move from `0.1.0`.

## Database migrations

None.

## Rollback

Direct rollback supported to 0.1.0. This release does not change the database.
