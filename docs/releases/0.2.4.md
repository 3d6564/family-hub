## Changes

A wall display shows a pairing code. An adult enters that code in Settings, then Screens. The code alone does not create a display session.

## Setup changes

Redeploy image `0.2.4` and reload the wall display. Pair it again from Settings, then Screens, if it is not already paired.

## Database migrations

Adds `display_pairings` for screen-initiated pairing. Existing household data is unchanged.

## Rollback

Direct rollback supported to 0.2.3. The previous image ignores the new table.
