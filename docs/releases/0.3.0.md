## Changes

Screen previews stay accurate to each display, but the Settings card fits the whole preview in a fixed area. A phone no longer appears larger than a wall display.

A new pairing saves the screen size when the adult approves the code.

## Setup changes

Redeploy image `0.3.0` and reload the browser address.

## Database migrations

None.

## Rollback

Direct rollback supported to 0.2.4. This release does not change the database.
