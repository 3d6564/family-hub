# Family Hub 0.3.3

## Changes

- Weather refresh now defaults to 30 minutes instead of 3 hours.
- Adults can choose 15 minutes, 30 minutes, 1 hour, or 3 hours in Settings > Weather.
- Active displays check the dashboard about every 5 minutes. Weather refresh
  happens on the next dashboard request after the selected interval expires.
- Faster refresh increases weather provider API use. A refresh can make several
  requests. Provider failures still show the last saved forecast.

## Setup changes

Select image `ghcr.io/3d6564/family-hub:0.3.3` in Portainer or set
`FAMILY_HUB_VERSION=0.3.3` for Compose. Pull and replace the application container.
Preserve the existing environment settings and data volume.

## Database migrations

Startup applies `024_weather_refresh.sql`. It adds a household refresh interval
with a 30-minute default, including for existing households. Save a pre-update
backup before replacing the container.

## Rollback

Direct rollback supported to 0.3.2. The new column has a default and does not
change existing columns. Version 0.3.2 ignores it and uses its 3-hour cache.
