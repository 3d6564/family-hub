# Family Hub 0.3.6

## Changes

- Sort calendar events by start time across calendars and local reminders, so
  morning events appear before evening events within each day.
- Compare timed events by their actual timestamps, including time-zone offsets.
- Keep calendar order as the tie-breaker when start times are equal.

## Setup changes

Use image `ghcr.io/3d6564/family-hub:0.3.6` with the existing environment and
data volume. No dependency or kiosk-installer changes. Reload the calendar
after deployment if the browser has not reloaded automatically.

## Database migrations

None since 0.3.5.

## Rollback

Direct rollback supported to 0.3.5. Select the previous image with the same
environment and data volume, then reload the browser. Save a backup before
updating. For upgrades from older versions, review each intervening release.

## Verification

- `npm run check`
- `npm test`, including calendar ordering across feeds, local reminders,
  all-day events, equal start times, and time-zone offsets
- Optional browser checks require `FAMILY_HUB_TEST_BROWSER`; not run locally
- AMD64 image smoke test (required by the release workflow)
- ARM64 image smoke test (required by the release workflow)

Live household events and kiosk appearance have not been inspected. Deployment
and live verification are separate from release publication.
