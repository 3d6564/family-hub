# Family Hub 0.4.2

## Changes

- Add 16 device color palettes in a compact Appearance popup. The 12 added
  palettes are device-only; the household default remains Green, Slate, Blue,
  or Warm.
- Use a palette-colored card background and three overlapping color circles
  layered from left to right in each palette preview.

## Setup changes

Use `ghcr.io/3d6564/family-hub:0.4.2`. Save a backup before updating. Preserve
the existing data volume, environment values, and `FAMILY_HUB_INTEGRATION_KEY`.
For Portainer, set `FAMILY_HUB_VERSION=0.4.2`, pull the image, and redeploy only
the application container. Reload open browsers after deployment. No kiosk
installer changes are required. Publication does not update a host.

## Database migrations

No database migration. The palette selection is saved in each browser's local
storage and does not change household data.

## Rollback

Direct rollback to 0.4.1 is supported. No database restore is required. Restore
the previous image and reload open browsers.
See the [recovery guide](../update-and-recovery.md).

## Verification

- `npm run check` through the Node.js 22 development container.
- `npm test` with Chromium, including checks for all 16 palettes, card
  backgrounds, left-to-right circle layering, and phone and desktop layouts.
- AMD64 and ARM64 image builds, smoke tests, and display installer asset checks
  must pass in the release workflow before publication.
