# Family Hub 0.4.3

## Changes

- Send AnyList writes using the upstream binary form-field format. Match the
  upstream lowercase UUID format for new items.
- Keep acknowledged additions visible until AnyList confirms them, and mark the
  list stale while confirmation is pending.
- Increase paired-display keyboard key height to reduce cramped keys.

## Setup changes

Use `ghcr.io/3d6564/family-hub:0.4.3`. Save a backup before updating. Preserve
the existing data volume, environment values, and `FAMILY_HUB_INTEGRATION_KEY`.
For Portainer, set `FAMILY_HUB_VERSION=0.4.3`, pull the image, and redeploy only
the application container. Reload open browsers after deployment. No kiosk
installer changes are required. Publication does not update a host.

## Database migrations

No database migration.

## Rollback

Direct rollback to 0.4.2 is supported. No database restore is required. Restore
the previous image and reload open browsers.
See the [recovery guide](../update-and-recovery.md).

## Verification

- `npm run check` through the Node.js 22 development container.
- `npm test` with Chromium, including AnyList request encoding, delayed provider
  confirmation, and keyboard sizing checks.
- AMD64 and ARM64 image builds, smoke tests, and display installer asset checks
  must pass in the release workflow before publication.
