# Family Hub 0.4.4

## Changes

- Improve night-mode contrast for text, calendar events, calendar day borders,
  and today's cell across all 16 palettes. Keep palette-specific accents.

## Setup changes

Use `ghcr.io/3d6564/family-hub:0.4.4`. Save a backup before updating. Preserve
the existing data volume, environment values, and `FAMILY_HUB_INTEGRATION_KEY`.
For Portainer, set `FAMILY_HUB_VERSION=0.4.4`, pull the image, and redeploy only
the application container. Reload open browsers after deployment. No kiosk
installer changes are required. Publication does not update a host.

## Database migrations

No database migration.

## Rollback

Direct rollback to 0.4.3 is supported. No database restore is required. Restore
the previous image and reload open browsers.
See the [recovery guide](../update-and-recovery.md).

## Verification

- `npm run check` through the Node.js 22 development container.
- `npm test` with Chromium, including color-contrast checks for all 16 palettes
  and narrow and wide viewport checks.
- AMD64 and ARM64 image builds, smoke tests, and display installer asset checks
  must pass in the release workflow before publication.
