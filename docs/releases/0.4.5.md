# Family Hub 0.4.5

## Changes

- Improve task screen hierarchy, Lists status messages, and settings contrast.
- Move desktop appearance, mode, and Settings controls into the left rail.
- Use consistent rail icons and dark-mode palette previews.

## Setup changes

Use `ghcr.io/3d6564/family-hub:0.4.5`. Save a backup before updating. Preserve
the existing data volume and environment values. For Portainer, set
`FAMILY_HUB_VERSION=0.4.5`, pull the image, and redeploy only the application
container. Reload open browsers after deployment. No kiosk installer changes are
required. Publication does not update a host.

## Database migrations

No database migration.

## Rollback

Direct rollback to 0.4.4 is supported. No database restore is required. Restore
the previous image and reload open browsers. See the
[recovery guide](../update-and-recovery.md).

## Verification

- `npm run check` through the Node.js 22 development container.
- `npm test` with Chromium, including desktop and phone navigation checks,
  dark-mode palette checks, and layout checks across 16 palettes.
- AMD64 and ARM64 image builds, smoke tests, and display installer asset checks
  must pass in the release workflow before publication.
