# Family Hub 0.5.0

## Changes

- Add an optional, read-only Google Calendar connection with selectable
  calendars. Family Hub encrypts the OAuth client secret and refresh token at
  rest.
- Manage public iCal feeds and Google Calendar together under Integrations.
  AnyList remains a separate integration card.
- Improve the integration layout and calendar inventory on phone and desktop
  screens.

## Setup changes

Use `ghcr.io/3d6564/family-hub:0.5.0`. Save a backup before updating. Preserve
the existing data volume, environment values, and
`FAMILY_HUB_INTEGRATION_KEY`. For Portainer, set `FAMILY_HUB_VERSION=0.5.0`, pull
the new image, and redeploy only the application container. Reload open browsers.
No kiosk installer changes are required. Publication does not update a host.

Google Calendar is optional. To connect it, enable the Google Calendar API,
create a Google OAuth web client, and register
`https://your-hub.example/api/integrations/google-calendar/callback` with the
exact host in `SITE_URL`. Set `FAMILY_HUB_INTEGRATION_KEY` before saving OAuth
credentials in Settings. The updated `compose.yaml` passes optional
`GOOGLE_OAUTH_CLIENT_ID` and `GOOGLE_OAUTH_CLIENT_SECRET` fallback values to the
container. See the [Google Calendar guide](../google-calendar.md) and
[Portainer guide](../portainer.md).

## Database migrations

Migrations `028_google_calendar.sql` and
`029_google_calendar_oauth_settings.sql` add household-scoped tables for the
Google connection and OAuth client settings. They run on startup and do not
rewrite existing household records. The integration key is not included in
database backups; retain it securely to use encrypted Google credentials after
a restore.

## Rollback

Direct rollback to 0.4.5 is supported. The migrations only add tables, which
0.4.5 ignores. Existing data does not need to be restored. Google Calendar
settings remain in the database but are unavailable until Family Hub is updated
to 0.5.0 again. Restore the previous image with the same environment and data
volume, then reload browsers. See the
[recovery guide](../update-and-recovery.md).
