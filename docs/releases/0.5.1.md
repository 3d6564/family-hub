# Family Hub 0.5.1

## Changes

- Manage saved iCal and Google calendars in one compact list. See source and
  connection status, enable or disable each calendar, choose its color, and
  remove it from Family Hub.
- Test an iCal connection before saving the feed.
- Save Google calendar colors and enabled states across household devices.
  Removing a Google calendar does not change the Google account or its data.

## Setup changes

Use `ghcr.io/3d6564/family-hub:0.5.1`. Save a backup before updating. Preserve
the existing data volume, environment values, and `FAMILY_HUB_INTEGRATION_KEY`.
For Portainer, set `FAMILY_HUB_VERSION=0.5.1`, pull the new image, and redeploy
only the application container. Reload open browsers. No kiosk installer
changes are required. Publication does not update a host.

## Database migrations

None.

## Rollback

Direct rollback to 0.5.0 is supported. No schema changes are required. Version
0.5.0 does not use the per-calendar Google color or enabled settings. A catalog
refresh under 0.5.0 can replace those settings with provider defaults. Set them
again after upgrading to 0.5.1. Restore the 0.5.0 image with the same environment
and data volume, then reload browsers. See the
[recovery guide](../update-and-recovery.md).

## Verification

- `npm run check` through the Node.js 22 development container.
- `npm test` through the Node.js 22 development container, including Chromium
  browser checks.
- Browser layout checks cover 390, 760, 1024, 1440, and 1920 pixel widths.
- AMD64 and ARM64 image builds, smoke tests, and display installer asset checks
  must pass in the release workflow before publication.
- Live Google Calendar account behavior has not been tested.
