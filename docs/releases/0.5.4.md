# Family Hub 0.5.4

## Changes

- Reduce the spacing of chore and routine rows in the calendar sidebar. Version
  0.5.2 added 12px of padding to every check row, which made wide-layout rows
  about 50px tall. Those rows now use the calendar's 28px height.
- Reduce routine period headings in the same wide calendar layout from 42px to
  28px.
- Keep 44px touch rows at other screen sizes. Chores and routines on their own
  pages are unchanged.

## Setup changes

Use `ghcr.io/3d6564/family-hub:0.5.4`. Save a backup before updating. Preserve
all existing environment values, the data volume, and
`FAMILY_HUB_INTEGRATION_KEY`. For Portainer, set `FAMILY_HUB_VERSION=0.5.4`,
pull the image, and redeploy only the application container. Reload open
browsers after replacement. No kiosk installer changes are required.
Publication does not update a host.

## Database migrations

None. No schema or dependency changes.

## Rollback

Direct rollback to 0.5.3 is supported. Restore the 0.5.3 image with the same
environment values, integration key, and data volume, then reload browsers.
See the [recovery guide](../update-and-recovery.md).

## Verification

- `npm run check` and `npm test` passed through the Node.js 22 development
  container with browser tests enabled. The calendar sidebar test measures
  1440x1000 and 1280x720 and saves a 390x844 screenshot for review.
- AMD64 and ARM64 builds, smoke tests, and display installer asset checks must
  pass in the release workflow before publication.
- Production deployment remains a separate host operation.
